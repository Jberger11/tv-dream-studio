## 遊戲內容

- 新局開台資金為 HK$3,000 萬；舊存檔現金保持原額。開局直接進入每日排播表：點時段可改節目，底部可以播出今日或連續營運最多 7 日；播出後即時顯示盈虧及對台勝出時數。
- 底部六個功能鍵分別進入排播、製作、片庫、對手、體育及戰報。新製作或購入節目後會直接帶你回排播表安排時段。
- 戰報逐小時列明我台、全城電視、本地八台嘅收視指數（遊戲內 0–100 分，並非收視率百分比）；我台高過兩間對手先算勝出。可篩選黃金檔或落後時段，廣告收入另列。
- 每週七日各有 24 格、每格 1 小時的排播表；24 格固定時間軸同畫面可見，毋須在表內上下捲動。可選每日、週一至五、週六日或每週一次。排播時可搜尋節目，亦可按未排、自製、外購、每日或開台片庫篩選，卡片列出已排時段及剩餘集數；同日另一時段重播須明確開啟。一般節目每集 1–4 小時。頂部「正在播映」採用遊戲時鐘，現實 30 秒推進遊戲 1 小時；只在頁面可見、玩家處理首播決策以外時運行，到 24:00 暫停，按「播出今日」才結算並開始新一日。遊戲時鐘唔跟香港實際時間，唔會喺背景自動扣錢或跳集。
- 新製作或外購節目首次真正播出後，按劇集、綜藝、深夜、新聞、財經等類型顯示首播戰報，比較當日對手收視。首播勝負會改變後續話題與預測收視；你可付費宣傳、改善內容，或免費穩陣播出。選擇會保存，快進在待處理首播前停下；開台已排好的節目不會逐一彈出首播戰報。
- 開局已有節目庫及排好的節目；劇集、綜藝、深夜節目、新聞、財經、資訊、政治、社會議題等可以製作與播映。深夜節目安排於 22:00–02:00 有收視優勢，放喺日間會吃虧。
- 可自製慈善夜、才藝大賽、選美盛典：均屬一次性大型直播，黃金檔及週末有額外收視優勢，播完自動騰空時段。慈善夜籌款與台現金分開計算，增加口碑；才藝大賽提升熱度；選美盛典有較高廣告回報，亦可能因評審風波影響口碑。每日結算直接打開戰報，顯示每次播映的我台及最強對手收視、廣告收益及活動後果，保留最近七日逐套成績；返回排播頁仍可一眼看清時間格。
- 新製作的新聞與財經節目都每日出新一期：先付首期成本，往後每次播映再付一集製作費，毋須設定總集數。財經節目觀眾較少，但同收視指數下廣告單價較高。舊存檔中已預付整季的有限集數財經節目保持原有集數及成本，不會追收每日費用。
- 製作可選預算、每集時長、集數、製作風格、額外企劃橋段和主演；電視劇主演 2–4 位。只要資金足夠，同一季可以繼續開拍，並無三套上限。街頭實景及觀眾參與增加成本與回報；大膽特技可能成功亦可能出事。藝人知名度和身價隨收視調整。
- 自製節目可以授權畀全城電視或本地八台換取現金，我台仍可播，但對方 30 日內會安排晚間播映，同我台爭收視；亦可獨家賣斷收取較高價，但我台即時落畫、不能再排播。同一作品不能重複賣畀同一台。
- 自製有限集數節目播完最後一集後立即從節目表清走，片庫保留紀錄；空出時段沒有廣告收入。外購節目可選 180 日或 360 日版權，一輪播完亦會清出時段，**不會自動重播**。版權有效期內可在片庫明確選「重播一輪」再自行排檔，電影重映亦一樣；每輪重播收視與話題逐步下降，底線為原來的 72%。到期後可在片庫續購。舊存檔中已經自動重播中的節目會停止排播，但原有現金、播映次數和播映權不變。連續營運及快進會在節目播完或版權到期時停低，方便補位。新聞等每日更新節目不設集數上限。
- 外購片庫改為顯示成套節目「已完整播出 X 次」（電影顯示「已放映 X 次」）；只計完成的整套播映，例如 20 集節目累計播出 61 集會顯示完整播出 3 次。排播選片另外按本輪計算尚餘集數。舊版曾自動重播而累積的歷史逐集紀錄仍保留在存檔，不會重設。
- 自製首播的廣告收入按收視指數平方計算，好節目可回本，差節目可以蝕錢；免費開局節目屬低收益的非獨家播映權。劇種與題材相性，以及劣配的隱藏 Cult 逆襲與冷卻；真實香港電影片名及其他類型外購節目。
- 外購市場每 30 個遊戲日更新 20 套輪換作品，換月會在快進途中停低；已購入播映權仍有效。玩家提供的 2020–2026 年 ViuTV 原創劇名單共 47 套長期可選；片庫可按台、年份、劇名和類型篩選。原有外購作品 ID 保留，舊存檔的資金、版權和排播不改。作品年份按玩家名單整理；遊戲內集數、價錢及收視數據皆為模擬。
- 兩間對手每月推出黃金檔新節目，實際影響我台對台收視；對手頁可看本月首播、下月預告和逐小時節目表。戰報有按模擬收視產生的觀眾留言；觀眾信箱會收到點播要求、禮物或投訴，回信可影響下一套作品或台口碑。另有重大體育賽事暗標拍賣。

## 本機啟動

不需要安裝依賴。在此目錄執行：

```sh
python3 -m http.server 8000
```

然後開啟 http://localhost:8000/ 。本作的檔案均位於此目錄；請用本機 HTTP 伺服器開啟 ES 模組。遊戲資料儲存於瀏覽器本機。

遊戲會自動存檔；重新載入同一個瀏覽器仍會保留現金、節目、排播及競投進度。「重新開局」會清除目前遊戲進度。此版本已在瀏覽器模擬 320px／390px 觸控畫面檢查，仍需真機測試。
